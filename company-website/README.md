# موقع شركة الريادة

موقع تعريفي لشركة: HTML5 وCSS3 وJavaScript، بلا أي مكتبات خارجية، ومتجاوب مع الجوال.

## هيكل الملفات
```
index.html        الصفحة الرئيسية
404.html          صفحة الخطأ
css/style.css     التنسيقات
js/main.js        التفاعل (القائمة، السلايدر، العدادات، النموذج)
assets/favicon.svg الشعار
```

## تخصيص المحتوى
- اسم الشركة: ابحث عن «الريادة» في index.html و404.html.
- البريد: غيّر `info@example.com` في index.html وفي `CONTACT_EMAIL` داخل js/main.js.
- الهاتف: غيّر `+966500000000`.
- الألوان: عدّل المتغيرات في أعلى css/style.css (`--primary`, `--accent`).
