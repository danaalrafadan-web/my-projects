# مساعد الدوام

صفحة ويب واحدة يكتب فيها الموظف سؤاله عن الحضور أو التأخير أو الاستئذان، والصفحة ترسل السؤال لـ Claude وتعرض الرد باللهجة السعودية.

القواعد (بيانات تجريبية):
- الدوام من 8 الصباح إلى 4 العصر
- التأخير المسموح 15 دقيقة
- الاستئذان ساعتين بالكثير

الرابط: https://claude.ai/artifact/Jewup6DSZySDdHMJiG12cU

## وين ألقى AI_INSTRUCTIONS؟
في ملف `index.html`، أول شي في الملف، بين هذين السطرين:

```
// ===== تعليمات الذكاء الاصطناعي: عدلها من هنا =====
...
// ===== نهاية التعليمات =====
```

## كيف أعدلها؟
1. افتح `index.html` وعدل السطر اللي تبيه. مثلاً غير `اللهجة: سعودية` إلى `اللهجة: مصرية`، أو عدل القواعد في خانة المهمة.
2. احفظ الملف.
3. اطلب من Claude: "انشر الصفحة مرة ثانية". الرابط يبقى نفسه.

ملاحظة: إذا غيرت أرقام القواعد، عدلها كمان في البطاقات الثلاث اللي فوق الصفحة (قسم `rules`).
