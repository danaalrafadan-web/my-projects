# مخطط الرحلات

## وش يسوي المشروع؟
صفحة وحدة تكتب فيها الوجهة وعدد الأيام والميزانية والاهتمامات، وتسأل Claude، وترجع لك برنامج رحلة يوم بيوم.

الرابط: https://claude.ai/artifact/8Usrz8REon4EkqQF6jnSWR

## وين ألقى AI_INSTRUCTIONS؟
في ملف `trip-planner.html`، وهي أول شي في الكود بين هالسطرين:

```
// ===== تعليمات الذكاء الاصطناعي: عدلها من هنا =====
...
// ===== نهاية التعليمات =====
```

## كيف أعدلها؟
1. افتح `trip-planner.html` وعدّل النص اللي بين السطرين، مثل الدور أو الطول أو اللهجة (مثلاً تكتب "مصرية" بدل "سعودية").
2. خل اسم `AI_INSTRUCTIONS` والسطرين مثل ما هم.
3. اطلب من Claude: "انشر الصفحة مرة ثانية"، وبيتحدث نفس الرابط.

## ملاحظة
أي شي داخل الصفحة يقدر يشوفه اللي يفتحها، فلا تحط فيها كلمات سر أو معلومات شخصية.
